# GB1 model

`GB1FlipCNN` reproduces the supervised, non-pretrained FLIP baseline: a width-5 convolution with 1,024 channels, ReLU, per-position projection to 2,048 dimensions, sequence max pooling and scalar regression. Reference: Dallago et al., *FLIP: Benchmark tasks in fitness landscape inference*, NeurIPS 2021 datasets/benchmarks.
