# GFP model

`GFPDesignBenchTransformer` is the Design-Bench GFP oracle architecture: hidden size 64, feed-forward size 256, two heads and four encoder blocks. It is randomly initialized and trained only on the Sarkisyan measurements—there is no protein-language-model pretraining or fine-tuning. Reference: Trabucco et al., Design-Bench, ICML 2022.
