# WeakSeqCNN-v1：统一 DNA/RNA 序列优化 Surrogate 模型实现规范

请实现一个统一的、轻量级、可微分的序列回归模型 **WeakSeqCNN-v1**，用于 biological sequence optimization benchmark。

当前 benchmark 仅包含：

* DNA sequence tasks
* RNA sequence tasks

不包含 protein sequence tasks。

为了统一输入表示，所有 RNA 序列中的：

```text
U
```

在预处理阶段统一转换为：

```text
T
```

因此所有任务统一使用 DNA alphabet：

```text
A, C, G, T
```

即：

```text
alphabet_size = 4
```

模型目标不是达到 SOTA，而是保证：

* 所有任务使用完全一致的模型架构；
* DNA 和 RNA 统一使用 A/C/G/T one-hot；
* 模型轻量、训练稳定；
* 支持 variable-length sequence；
* 支持 gradient-based sequence optimization，例如 Fast SeqProp；
* 无预训练；
* 不使用 foundation model；
* 不使用 Transformer；
* 参数量尽量控制在约 150K–300K。

---

## 1. 总体架构

模型结构：

```text
Input DNA/RNA sequence
    ↓
RNA: U → T
    ↓
A/C/G/T one-hot encoding
    ↓
1×1 Conv input projection
    ↓
Add relative positional features
    ↓
Residual Dilated Conv1D Block × 4
    ↓
Mean Pooling
    +
Max Pooling
    +
Attention Pooling
    ↓
Concatenate pooled features
    ↓
Dense 128
    ↓
GELU
    ↓
Dropout 0.1
    ↓
Linear regression head
    ↓
Predicted activity / fitness
```

## 2. 输入

统一输入 tensor：

```python
x.shape = [batch_size, length, 4]
```

所有 DNA 和 RNA 都使用：

```text
A
C
G
T
```

编码。

RNA 数据预处理：

```python
sequence = sequence.upper().replace("U", "T")
```

随后统一做 one-hot encoding。

推荐 mapping：

```python
base_to_index = {
    "A": 0,
    "C": 1,
    "G": 2,
    "T": 3,
}
```

模型输入可以是：

### Hard one-hot

例如 G：

```text
[0, 0, 1, 0]
```

也必须支持：

### Soft one-hot / nucleotide probability

例如：

```text
[0.05, 0.10, 0.80, 0.05]
```

因为后续要做 differentiable sequence optimization。

因此：

```python
x.dtype = torch.float32
```

模型内部禁止使用：

```text
argmax
integer tokenization
sampling
detach
```

## 3. Input projection

输入：

```text
[B, L, 4]
```

转换为 channels-first：

```python
x = x.transpose(1, 2)
```

得到：

```text
[B, 4, L]
```

然后：

```python
nn.Conv1d(
    in_channels=4,
    out_channels=64,
    kernel_size=1
)
```

输出：

```text
[B, 64, L]
```

由于所有 DNA/RNA 任务均统一使用 A/C/G/T，因此：

```text
in_channels = 4
```

在所有 benchmark task 中必须保持不变。

---

## 4. Relative positional features

为了保留序列中 motif 的相对位置，引入两个位置通道。

对于长度：

```text
L
```

第 i 个位置：

```python
forward_position = i / (L - 1)
reverse_position = 1 - forward_position
```

形成：

```text
[B, 2, L]
```

与 sequence representation concatenate：

```text
[B, 64, L]
+
[B, 2, L]
=
[B, 66, L]
```

然后通过：

```python
nn.Conv1d(
    in_channels=66,
    out_channels=64,
    kernel_size=1
)
```

重新投影为：

```text
[B, 64, L]
```

如果存在 padding，position 必须根据真实 sequence length 计算，而不是 padded length。

---

## 5. Residual Dilated CNN Backbone

统一使用 4 个 residual convolution blocks。

所有任务：

```text
channels = 64
kernel_size = 5
```

dilation：

```text
Block 1: 1
Block 2: 2
Block 3: 4
Block 4: 8
```

每个 residual block：

```text
Input
  │
  ├───────────────────────────────┐
  │                               │
Conv1D                            │
  ↓                               │
GroupNorm                         │
  ↓                               │
GELU                              │
  ↓                               │
Dropout                           │
  ↓                               │
Conv1D                            │
  ↓                               │
GroupNorm                         │
  ↓                               │
GELU                              │
  ↓                               │
Dropout                           │
  │                               │
  └──────── Add residual ─────────┘
                  ↓
                GELU
```

卷积：

```python
nn.Conv1d(
    in_channels=64,
    out_channels=64,
    kernel_size=5,
    dilation=d,
    padding=2 * d
)
```

padding 必须保证：

```text
input_length == output_length
```

Normalization：

```python
nn.GroupNorm(
    num_groups=8,
    num_channels=64
)
```

不要使用 BatchNorm。

Activation：

```python
nn.GELU()
```

Dropout：

```python
nn.Dropout(0.1)
```

Residual：

```python
out = F.gelu(x + residual_branch)
```

## 6. Variable-length sequence 和 padding mask

模型必须支持不同长度 DNA/RNA 序列。

mask：

```python
mask.shape = [B, L]
```

定义：

```text
1 = real nucleotide
0 = padding
```

所有 pooling 操作必须支持 mask。

每个 residual block 后建议：

```python
h = h * mask.unsqueeze(1)
```

防止 padding signal 传播。

如果所有序列固定长度，也必须保留 mask 接口以保证统一。

---

## 7. Pooling

不要只使用 global max pooling。

统一采用：

* masked mean pooling
* masked max pooling
* attention pooling

---

### 7.1 Masked mean pooling

计算：

```python
mask_expanded = mask.unsqueeze(1)

mean_pool = (
    (h * mask_expanded).sum(dim=-1)
    /
    mask_expanded.sum(dim=-1).clamp_min(1)
)
```

输出：

```text
[B, 64]
```

---

### 7.2 Masked max pooling

对于 padding position：

```text
-inf
```

然后：

```python
max_pool = masked_h.max(dim=-1).values
```

输出：

```text
[B, 64]
```

---

### 7.3 Attention pooling

输入：

```text
h = [B, 64, L]
```

转换：

```python
h_t = h.transpose(1, 2)
```

得到：

```text
[B, L, 64]
```

每个位点 attention score：

```python
score = nn.Linear(64, 1)(h_t)
```

得到：

```text
[B, L, 1]
```

padding position：

```text
score = -inf
```

然后：

```python
attention = softmax(score, dim=1)
```

最终：

```python
attention_pool = (attention * h_t).sum(dim=1)
```

输出：

```text
[B, 64]
```

不要使用：

* multi-head attention
* self-attention block
* Transformer encoder

attention 只用于 pooling。

---

## 8. Feature concatenation

三个 pooling feature：

```python
features = torch.cat(
    [
        mean_pool,
        max_pool,
        attention_pool,
    ],
    dim=-1
)
```

得到：

```text
[B, 192]
```

---

## 9. Regression head

统一使用：

```python
Linear(192, 128)
GELU
Dropout(0.1)
Linear(128, 1)
```

输出：

```text
[B]
```

最后一层不加：

```text
Sigmoid
Softmax
ReLU
```

即：

```text
prediction ∈ (-∞, +∞)
```

适合：

* promoter activity
* enhancer activity
* translation efficiency
* RNA stability
* TF binding affinity
* fluorescence-derived regulatory output
* other continuous sequence-function labels

## 11. Label normalization

每个数据集独立计算 training split 的：

```python
label_mean
label_std
```

训练：

```python
y_norm = (y - train_mean) / train_std
```

预测后恢复：

```python
y_original = prediction * train_std + train_mean
```

注意：

只能使用 training split 的统计量。

禁止使用：

```text
validation
test
full dataset
```

计算 mean/std。

## 20. Gradient-based sequence optimization 兼容性

必须支持：

```text
sequence logits
      ↓
softmax
      ↓
soft nucleotide probabilities
      ↓
WeakSeqCNN
      ↓
activity score
```

例如：

```python
sequence_logits = torch.randn(
    batch_size,
    length,
    4,
    requires_grad=True
)

sequence_probabilities = torch.softmax(
    sequence_logits / temperature,
    dim=-1
)

score = model(sequence_probabilities)

loss = -score.mean()
loss.backward()
```

必须满足：

```python
sequence_logits.grad is not None
```

模型内部禁止：

```text
argmax
round
sampling
integer conversion
detach
numpy conversion
```

确保梯度完整传播到 nucleotide logits。

## 27. 最终公平原则

当前 benchmark 中所有 task 都属于：

```text
DNA/RNA sequence → quantitative biological function
```

因此使用统一：

```text
A/C/G/T representation
+
same CNN backbone
+
same pooling
+
same regression head
```

整个 benchmark 中：

```text
RNA U is treated as DNA T
```

因此模型完全不需要知道：

```text
这个序列原本来自 DNA 还是 RNA
```

数据集来源和 molecule type 仅作为 metadata 保留。

最终目标：

```text
Different biological datasets
        ↓
same standardized surrogate
        ↓
different sequence optimizers
        ↓
independent strong predictors / experimental truth
        ↓
compare optimization reliability
```

从而保证不同 optimization methods 的比较尽可能不受 surrogate architecture 差异影响。
